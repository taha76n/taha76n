## 🚀 Selected Projects

### 🚚 DispatchX — Real-Time Food Delivery Dispatch Platform

**MERN Stack · TypeScript · Redis · RabbitMQ · Socket.io · React-Leaflet**

A full-stack food delivery platform designed around real-time order dispatch and rider coordination.

* Role-based workflows for **customers, restaurants, and riders**
* Type-safe order state machine shared across frontend and backend
* Rider dispatch using **Redis geospatial queries**
* Sequential delivery offers using **RabbitMQ delayed messages**
* Automatic timeout, decline handling, and fallback to the next rider
* Horizontally scalable Socket.io using the **Redis adapter**
* Live rider location tracking with React-Leaflet
* Redis-backed **idempotency** and sliding-window rate limiting

[**View Repository →**](https://github.com/taha76n/DispatchX)

**Node.js · MongoDB · Apache Kafka · Redis · Docker**

A distributed railway booking system built around independent services and transactional workflows.

* Distributed booking and payment workflow using the **Saga pattern**
* API Gateway with routing, JWT authorization, and circuit-breaker handling
